# Power-Bi-Dashboard
📊 IT Expenditure Dashboard (Power BI)

This Power BI dashboard provides a complete analysis of IT expenditure data across different business areas, countries, and cost elements. It helps organizations monitor actual spending, forecast values, plan variance, and overall IT performance.

🚀 Dashboard Features
KPI Cards for:
Total Actual
Total Forecast
Total Plan
Overall Budget
Utilization %
Variance %
Monthly Analysis:
Total Actual vs Forecast vs Plan by Month
Business Area Insights:
Comparison across Infrastructure, Manufacturing, BU Support, Governance, etc.
Cost Element Analysis:
Plan vs Actual variance by cost element
Country-wise Variance Table:
Highlights overspending and underspending across countries
Interactive Filters/Slicers:
Business Area
IT Area
Month
🛠 Tools Used
Power BI Desktop
DAX
Power Query
Data Modeling
📈 Key Insights
Track budget utilization efficiently
Identify high expenditure business units
Analyze country-wise spending performance
Compare planned vs actual expenses visually
